# Plans

The [roadmap](../ROADMAP.md) controls the current queue. The SDK foundation, cleanup configuration, reopen/inspect, read cancellation, E2B text streaming, output helpers, timeout clarification, lifetime renewal, [default creation and everyday files](../specs/sandbox-basics-dx.md) (#58, #59, #61), and [preview access](../specs/preview-and-process-control.md) (#60) are merged. Exported directory APIs retain unsupported native mappings; preview supports Daytona protected and E2B explicit public access, with E2B default creation/restore private and protected preview unavailable. Native suspend/resume (#57) and E2B local-handle termination (#66) are merged, with scoped live passes at their recorded revisions. Termination retains native PID-reuse and descendant limitations; Daytona termination remains unsupported. Stdin and sustained output are separate next slices. Selected-volume Daytona cold restore merged in #69, with its complete live workflow passing at `5911ccc`. #68 records files, renewal, reopening, E2B directories/streaming and supported previews at `3188e33`; configured creation, private ingress, failed network evidence and historical volume uncertainty remain separate follow-ups. New providers stay behind SDK usability.

The [implementation sequence](implementation-plan.md) records delivery boundaries, and the [provider acceptance plan](provider-acceptance.md) records the merged Bun runner direction. Engineering contracts and proposals live in [specs](../specs/README.md), public documentation in [apps/docs](../apps/docs/README.md), and qualification guidance [with its harness](../packages/sdk-qualification/README.md).

Completed and superseded plans remain in Git history; they do not define current requirements or release gates.
