# Plans

[Current implementation sequence](implementation-plan.md) records selected work and deferrals. SDK state portability and observability are in progress: snapshot and core volume operations are implemented in the direct SDK, while suspension, lifetime controls and optional volume versions remain planned. Interactive execution and provider expansion follow. Service expansion is a distant milestone after SDK maturity and broader provider qualification.

Engineering contracts and proposals live in [specs](../specs/README.md), public documentation in [apps/docs](../apps/docs/README.md), and qualification guidance [with its harness](../packages/sdk-qualification/README.md).

Completed and superseded plans have been removed. Git history preserves them; they do not define current requirements or release gates.
