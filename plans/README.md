# Plans

The [roadmap](../ROADMAP.md) controls the current queue. The SDK foundation, cleanup configuration, reopen/inspect, read cancellation, E2B text streaming, output helpers, timeout clarification, lifetime renewal, [default creation and everyday files](../specs/sandbox-basics-dx.md) (#58, #59, #61), and [preview access](../specs/preview-and-process-control.md) (#60) are merged. Exported directory APIs retain unsupported native mappings; preview supports Daytona protected and E2B explicit public access, with E2B default creation/restore private and protected preview unavailable. Native suspend/resume remains open in #57; process termination is the next focused design/implementation, followed separately by stdin and sustained output. Storage composition (#56) remains a proposal, with coding after those basics; live qualification gaps remain separate. New providers stay behind SDK usability.

The [implementation sequence](implementation-plan.md) records delivery boundaries, and the [provider acceptance plan](provider-acceptance.md) records the merged Bun runner direction. Engineering contracts and proposals live in [specs](../specs/README.md), public documentation in [apps/docs](../apps/docs/README.md), and qualification guidance [with its harness](../packages/sdk-qualification/README.md).

Completed and superseded plans remain in Git history; they do not define current requirements or release gates.
