# sandbar-adapter

The public authoring API for Sandbar adapters, independent of the optional service. Packages are not yet published. Import `defineAdapter` from `sandbar-adapter`; `sandbar-adapter/testing` supplies conformance helpers.

Start with [Write an adapter](https://sandbarsdk.dev/docs/guides/write-an-adapter/), [capability checks](https://sandbarsdk.dev/docs/guides/adapter-capabilities/) and [asynchronous recovery](https://sandbarsdk.dev/docs/guides/adapter-recovery/). A minimal create/destroy adapter remains valid.

Optional state handlers expose scoped snapshots, volume inventory/deletion and create-time mounts. `snapshotProfiles` supplies read-only evidence: report unknown when a paid probe is needed, unavailable when access/configuration/state prevents support, and supported capture only with an installed capture handler. Profiles bind preservation, interruption, source lifecycle, consistency, connection handling, mounts and retention. Requirements validate one profile; never combine profiles to invent a guarantee. Missing retention cannot satisfy a positive minimum.

Resource references and operation checkpoints are application-owned JSON; native authentication, scope, identity and dependency checks still apply. Reads and preparation must not allocate or stop compute. Checkpoint before each stage dispatch and after learning evidence; failed persistence stops later effects. Observation never replays capture, restore or deletion. Explicit continuation may advance only a proven never-submitted stage; applications serialize it across processes. See the [recovery contract](https://sandbarsdk.dev/docs/guides/adapter-recovery/) and [typed recovery follow-up](../../specs/sdk-recovery-dx.md).

Advertise only implemented guarantees and keep qualification evidence distinct. E2B snapshot deletion requires a private containing template with exactly one build; stored history cannot authorize deleting unrelated generations. Native token/evidence handling belongs in the adapter, not application code. For the current public shapes, use the [TypeScript reference](https://sandbarsdk.dev/docs/reference/typescript/) and [state portability contract](../../specs/provider-state-portability.md).
